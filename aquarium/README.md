# ドットアクアリウム

スマホで遊べる、ドット絵のかわいいアクアリウム。

- 画面タップ：ごはんを落とす（魚が寄ってきて食べる）
- 魚をタップ：ハートが出る
- ＋さかな / ＋クラゲ：仲間を増やす
- 依存なしの `index.html` 1枚。GitHub Pages などでそのまま公開できます。

## つなぎかた（2台・サーバーなし）
1. 左がわのスマホ：「🔗 つなぐ」→「左がわになる」でQRを表示
2. 右がわのスマホ：「🔗 つなぐ」→「右がわになる」で左のQRを読む → 右にQRが出る
3. 左がわで「つぎへ」→ 右のQRを読む → つながる！

左の画面の右はしから出た魚は、右の画面の左はしから泳いで入ってきます。
QRが読めない時は「QRが読めないとき」の文字を AirDrop / LINE で送って貼り付けてください。
カメラを使うため HTTPS（GitHub Pages など）で開いてください。

`lib/` は jsQR（Apache-2.0）と qrcode-generator（MIT）。
