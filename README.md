# 💣 バクダンバトル

スマホでもPCでも、ブラウザを開くだけで遊べる **爆弾アクションゲーム**。
友達とオンラインで **対戦** も **協力** もできます。インストール不要・アカウント不要。

👉 **遊ぶ:** https://kodair918-del.github.io/bakudan-battle/

---

## 特徴

| | |
|---|---|
| 📱 **スマホ対応** | 画面下の方向パッドと爆弾ボタンで操作 |
| 💻 **PC対応** | キーボード操作。同じキーボードで2人対戦もできる |
| 🌐 **オンライン対戦** | 最大4人。ルームコードか招待URLを送るだけ |
| 🤝 **協力モード** | みんなでライフを共有して敵を全滅させる |
| 🤖 **CPU対戦** | ひとりでも遊べる。空き枠はCPUが埋める |
| 📦 **サーバー不要** | 静的ファイルだけ。通信はP2P（WebRTC） |

## 遊び方

### 目的
- **対戦モード** — 爆弾で相手を倒し、最後の1人になれば勝ち。
- **協力モード** — 仲間と一緒に敵キャラを全滅させれば勝ち。ライフは全員で共有。

### 操作

| | 移動 | 爆弾 |
|---|---|---|
| スマホ | 左下の方向パッド | 右下の丸ボタン |
| PC（1人目） | `W` `A` `S` `D` または矢印キー | `Space` |
| PC（2人目・ローカル2人対戦時） | 矢印キー | `Enter` |

### アイテム
壊せるブロックの中から出てきます。

- 🔥 **火** — 爆発の射程 +1
- 💣 **弾** — 同時に置ける爆弾 +1
- 👟 **速** — 移動スピードアップ

### コツ
- 爆風は十字に伸び、ブロック1枚で止まる。壁の裏が安全地帯。
- 自分の爆弾でも死ぬ。置いたらすぐ逃げる。
- 爆風は他の爆弾を誘爆させるので、連鎖に注意。

## 友達と遊ぶ手順

1. ひとりが「**オンラインでホスト**」を押す
2. 表示された **5文字のルームコード**、または「招待リンクをコピー」で出たURLを友達に送る
3. 友達は「**オンラインで参加**」からコードを入力（URLを開いた場合は自動で入力済み）
4. メンバーが揃ったらホストが「**ゲーム開始**」

> 通信はブラウザ同士の直接接続（WebRTC）です。出会わせ役（シグナリング）に
> PeerJS の公開サーバーを使うため、**初回接続時だけインターネット接続が必要**です。
> 職場や学校のネットワークなど、厳しいファイアウォール下では接続できないことがあります。
> その場合はローカルモード（ひとり／同じ端末で2人）で遊べます。

## 公開する（最初に1回だけ必要な設定）

GitHub Pages の有効化だけは、リポジトリの持ち主が画面から行う必要があります
（ワークフローの権限では有効化できません）。**1〜2分で終わります。**

1. リポジトリページ → **Settings**（設定）→ 左メニューの **Pages**
2. **Build and deployment** の **Source** を **GitHub Actions** に変更
3. **Actions** タブ → 左の *Deploy to GitHub Pages* → **Run workflow** を押す
   （以降はこのブランチに push するたび自動でデプロイされます）
4. 1分ほどで `https://<ユーザー名>.github.io/<リポジトリ名>/` が公開されます

> **もっと簡単な方法**: 手順2で **Source** を **Deploy from a branch** にして、
> ブランチと `/ (root)` を選んでも動きます。ビルド不要の素のHTMLなので、
> Actions を使わずそのまま配信できます。

## 手元で動かす

ES モジュールを使っているので、`index.html` をダブルクリックではなく簡易サーバー経由で開いてください。

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 技術メモ

- **ビルド不要** — 素の HTML / CSS / ES モジュール。依存は PeerJS（CDN）のみ
- **アセット不要** — キャラも背景も Canvas の図形描画、効果音は WebAudio で合成
- **通信方式** — ホスト権威型。ホストがシミュレーションを回し、20Hz でスナップショットを配信。
  ゲストは入力を 30Hz で送り、自分のキャラだけローカル予測＋補正で滑らかに表示
- **爆弾入力** — 押した回数のカウンタを送るため、パケットが落ちても設置が消えない
- **切断対応** — 試合中に誰かが落ちると、そのキャラは CPU が引き継ぐ

### ファイル構成

```
index.html          画面のマークアップ
styles.css          スタイル
src/engine.js       ゲームのルール（移動・爆弾・爆風・勝敗判定）
src/render.js       Canvas 描画
src/input.js        キーボード／タッチ入力
src/bots.js         CPU の思考（危険マップ＋BFS）
src/audio.js        WebAudio による効果音の合成
src/net.js          PeerJS による P2P 通信
src/main.js         画面遷移とゲームループ
```
